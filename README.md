# Sajay Chandran — portfolio

Personal portfolio of Sajay Chandran, a BCA student (Cyber Security & Ethical Hacking) in Bangalore.
Static site: plain HTML and CSS, no build step and no dependencies.

- `index.html` — homepage
- `frisyn.html` — Frisyn case study
- `wahat-al-zahar.html` — freelance case study
- `assets/` — shared stylesheet and optimised screenshots
- `Sajay_Chandran_Resume.pdf` — resume

To run it locally, open `index.html` in a browser. To deploy, point any static host at the repository root.
