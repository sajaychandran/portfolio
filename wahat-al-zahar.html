Brand & design

A brand built from scratch

No templates and no stock photos. I designed an ink-teal and brass palette, custom typography, and an original "trade-documentation" visual theme: stamp and seal motifs, crate iconography and an animated trade-route line, all drawn as custom SVG graphics.

The site is fully responsive and optimized for mobile, with restrained animation using Framer Motion.

Build & security

What I built

A marketing site, a careers system the client runs themselves, and two working forms on a serverless backend.

I used an AI-assisted development workflow: AI tools helped write the code, while the design, decisions, setup and delivery were mine.

Live careers system

Job vacancies live in Airtable. The client adds or removes openings there, with no code changes, and the careers page reads them live and handles an empty state gracefully.

Two working forms

A business inquiry form and a job application form with CV upload. Both write their submissions into Airtable.

  1. React site
  2. Netlify Functions
  3. Airtable

The serverless backend has endpoints for fetching jobs, submitting inquiries, and submitting applications with file upload.

Form security and SEO

  • CV files validated on the server by their actual binary signature, not just the extension
  • File-size limits and filename sanitization
  • Honeypot and submit-timing anti-spam on both forms
  • Meta tags and Open Graph
  • sitemap.xml and robots.txt
  • Submitted to Google Search Console
